# RV_Tank_Levels
This code uses ESP Home and a 4" ESP32 CYD to show Propane and Fresh Water Levels


This is the 3D model I used to hold the 4" ESP32 S3 CYD touchscreen - Note I had to stretch the X-axis by 1.02 to get this board to fit.  I also had to print 4 of the attached cylinders )spacers for the board) and use M3x6mm course Philips head screws to mount it.  I had to file the case area where the USB C cable plugs in to allow it to mount correctly.
